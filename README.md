# Brisa

A native macOS app to free up space safely: caches, logs and temporary files, large and old files, apps with their leftover data, and development resources (node_modules, pnpm/npm/Yarn caches, build folders, Docker and more). Brisa always shows what it found and asks before deleting anything.

This repository hosts Brisa **releases** and collects **bug reports and suggestions**. The app's source code is not here.

## Download

Download the latest `Brisa-<version>.dmg` from [Releases](https://github.com/JotaMiller/brisa-releases/releases/latest), open it and drag Brisa to *Applications*.

Requirements: macOS 14 or later. Available in English, French and Spanish.

> If macOS won't open the app the first time, go to *System Settings → Privacy & Security* and click “Open Anyway”.

Once installed, Brisa updates itself. You can also check from *Brisa → Buscar actualizaciones…* or in *Configuración → Actualizaciones*.

## Report a problem or suggest something

Open an [issue](https://github.com/JotaMiller/brisa-releases/issues/new/choose). Include your version (Configuración → Actualizaciones) and, if you can, the steps to reproduce it. Issues are public.

*For maintainers:* `appcast.xml` is the Sparkle update feed, served from GitHub Pages at `https://jotamiller.github.io/brisa-releases/appcast.xml`. It's generated by `Scripts/release.sh` in the app repository — don't edit it by hand.
